# Ryzer OS 3.2: built-in music, theme music, game banners and jingles

Date: 2026-10-30 · Status: design approved in conversation, pending written-spec review

## Why

The owner wants Ryzer to "feel like an actual 3DS-type console". They asked for:
- different kinds of background music people can pick by taste, all chill;
- themes that come with their own music;
- game banners with jingles.

Everything is original. No Nintendo music, sounds, logos or names are used.

## Success criteria

1. Eight original chill tracks ship in the APK. Each is a seamless loop, and together they add 5 MB or less to the APK.
2. *Settings → Sound & music* offers:
   - Music on/off.
   - Track: *Theme's music*, any single track, *Shuffle* or *Your music* (`RyzerOS/music`, as today).
   - Volume.
3. **Theme music:**
   - Every built-in theme names a track, and Home plays it.
   - The Themes picker and Theme Studio play *Shop Groove*.
   - Highlighting a theme in the picker for 1 s previews its track.
   - Settings plays the current track at half volume.
   - Track changes crossfade over 0.6 s.
4. **Fades:** music fades out when a game launches, comes back when Ryzer returns, and pauses when Ryzer goes to the background or the screen sleeps.
5. **Jingles:** resting on a game for 0.4 s (Home tiles that are games, and game lists) plays that system's original 1–2 s jingle, with the music dipped to 30% under it. *Game jingles* can be turned off.
6. **Banner:** the top-screen game card tilts gently in 3D with a light sweep, showing the title, year and system icon. It is static when animations are off.
7. **Defaults:**
   - New installs get music on at 40%.
   - Existing configs keep their music setting and get one Ryzer notice: "New: background music. Turn it on in Settings → Sound & music."
8. **Checks:** the emulator suite, stress test, screenshots and swap/update/artwork checks all pass, and the Home perf gate still holds.

## Design

### 1. Tracks (`tools/music/compose.py` → `android/app/src/main/assets/music/*.ogg`)

The composer is a Python script (numpy synthesis + ffmpeg/libvorbis) committed in the repo. It is deterministic (fixed seeds), so the tracks can be regenerated. Output is 44.1 kHz stereo OGG Vorbis at about 64 kbps.

| id | Name | Tempo | Instruments |
|---|---|---|---|
| `lofi` | Lo-fi Beats | 78 | dusty kick/snare/hat, electric-piano 7th chords, sub bass, vinyl crackle |
| `cafe` | Café Jazz | 96 | brushed snare, ride, walking bass, piano comping in ii–V–I |
| `bossa` | Bossa Breeze | 120 | plucked nylon-like chords in bossa rhythm, shaker, soft bass |
| `ambient` | Ambient Drift | 60 | slow detuned pads, bell motifs, no drums |
| `chiptune` | Soft Chiptune | 92 | mellow pulse lead, triangle bass, soft noise hats |
| `nightdrive` | Night Drive | 84 | warm saw pads, arpeggio, soft retro drums |
| `rain` | Rainy Day | 70 | sparse piano over filtered rain noise |
| `shop` | Shop Groove | 112 | bouncy jazz-pop: piano, bass, light drums |

- **Seamless loops:** each track is a whole number of bars. Reverb tails are wrapped back onto the start, so the end flows into the beginning.
- **Volume:** tracks are normalised to −16 LUFS-ish so they sit at the same level.

### 2. Player (`MusicPlayer`, replacing the menu-music code in `Looks.kt`)

- **Playback:** two `MediaPlayer`s crossfade, playing the asset (`AssetFileDescriptor`) or the user's file with `isLooping = true`.
- **API:**
  - `play(trackId, volumeScale)`
  - `duck(to, seconds)`
  - `fadeOut()`
  - `pause()` / `resume()`
- **Which track:** `Screen.music` (new, open property) returns the track a screen wants: `null` = keep the current one, `"shop"`, or `"theme"` = the theme's track. `Settings` screens return a half-volume scale.
- **Config:**
  - `musicTrack`: `theme` | `shuffle` | `user` | one of the eight ids. The default is `theme`.
  - The existing `music` and `musicVolume` fields stay.
  - On migration (config without `musicTrack`), `music` stays as it was, and a notice is shown once if it's off.

### 3. Theme music

- **Theme JSON:** an optional `style.music` (track id) and `style.sounds` (sound pack). Unknown values are ignored, and the Linux edition ignores both.
- **Built-in mapping:**

| Track | Themes |
|---|---|
| `nightdrive` | ryzer-strike, neon-night, vaporwave, cyberpunk |
| `lofi` | ryzer-red, lava, carbon, crimson-steel |
| `ambient` | ocean-deep, purple-haze, matrix, arctic |
| `chiptune` | gameboy, retro-amber (+ `sounds: chiptune`) |
| `cafe` | sunset, gold-rush, cherry-blossom |
| `bossa` | forest, mint |
| `rain` | midnight-blue, snow |

- **Theme Studio:** gains a *Music* row. Share codes include `music` because they carry `style`.

### 4. Jingles (`tools/music/compose.py` → `assets/jingles/<family>.ogg` + pitch per system)

- **Eight families:**
  - `nintendo-handheld` (gb, gbc, gba, nds, 3ds, ngpc, gamegear)
  - `nintendo-home` (nes, snes, n64, gc, wii, wiiu, switch)
  - `playstation` (psx, ps2, psp, psvita)
  - `sega` (mastersystem, genesis, segacd, saturn, dreamcast)
  - `arcade` (arcade)
  - `retro` (atari2600, pce)
  - `pc` (dos)
  - `generic`
- **Per-system variety:** each system has a pitch step (−3…+4 semitones), applied through `PlaybackParams.setPitch` on API 23+. With pitch unavailable, the plain family jingle plays.
- **Playback:** a `SoundPool` loads the 8 files once. `Jingles.play(system)` ducks the music to 30% for 1.6 s.
- **Trigger:**
  - Home (Blades, 3DS, Ribbon, Grid) and game lists start a 0.4 s timer when the selection lands on a game.
  - Moving cancels the timer, and the same game never replays until the selection changes.
  - No jingle while a game is launching.

### 5. Banner

On the top screen for a selected game (Blades hero, GameList details on top), the cover card gets:
- A tilt: `Camera` rotateY ±6° on a 6 s sine.
- A light sweep: the existing glint, every 4 s.
- A system-icon badge in its corner.

Battery saver and animations-off keep it still.

## Testing

- **Unit (JVM):**
  - every built-in theme's `music` is a known track;
  - every system id maps to a jingle family;
  - the jingle trigger logic (timer, cancel, no repeat) as a pure state machine.
- **Python:** `compose.py` writes eight tracks and eight jingles. Each loop's end and start join without a click (sample-difference check), loudness sits within ±2 dB, and the total size is ≤ 5 MB.
- **Emulator:**
  - `dumpsys media_session`/audio focus shows Ryzer playing on Home, and stopping after a game launch.
  - Shots: Settings → Sound & music, the theme picker with a preview, and the banner.
  - The stress test, crash gate and perf gate pass.
- **Listening:** a contact sheet of waveforms plus the owner's own ears after release. Nothing has been tested on real hardware yet.

## Out of scope

Coins/badges, Home folders, sleep-mode animation, StreetPass-style features, the Linux edition's music.
