Install in a minute

No root, no flashing. Ryzer is an app on top of your handheld's normal Android.

  1. On the handheld, download RyzerOS.apk and open it. Allow "install unknown apps" if Android asks.
  2. Start Ryzer OS and allow All files access so it can find your games.
  3. Put games in ROMs/<system> folders (ROMs/gba, ROMs/3ds, ROMs/ps2…) on internal storage or the SD card. ES-DE folder names work too.
  4. Pick your emulators in Settings → Emulators. Ryzer knows how to start 27 of them directly.
  5. Optional: Settings → Set as home screen makes Ryzer start when the handheld turns on.

FAQ

Is it a real operating system?

No, and it doesn't need to be. The Android edition is a launcher app on your stock OS, and the Linux edition runs on top of ROCKNIX, Knulli, muOS or ArkOS. Ryzer replaces how the handheld looks and feels; the firmware still provides the drivers.

Does it include games or emulators?

No. Ryzer launches the emulators you install, and you bring your own legally obtained games. The game names and covers in the screenshots are placeholders from a sample library.

Will updating erase my setup?

No. Installing a new APK over the old one keeps your settings, themes and play history, which live in the RyzerOS folder on your storage.

Something broke. How do I report it?

If Ryzer ever closes by itself, it saves the error to RyzerOS/crash.txt and shows it on the next start. Open an issue on GitHub and paste it in.
